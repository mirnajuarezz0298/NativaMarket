# NativaMarket — Navigation Flow

| | Catálogo (home) | Ficha de producto |
|---|---|---|
| **Purpose** | Punto de entrada: mostrar de un vistazo los productos hechos en Guatemala y dejar que la persona los explore. | Darle a la persona todo lo que necesita para decidirse por un producto y comprarlo con confianza. |
| **Information shown** | Por cada producto: foto, nombre, fabricante, lugar de origen (sello de origen), precio y si está disponible. | Del producto elegido: foto, nombre, fabricante, lugar de origen, una descripción, precio y disponibilidad. |
| **Actions** | Explorar el catálogo, filtrar por categoría y abrir un producto para ver más. | Agregar el producto al carrito, o pedir aviso si está agotado, y regresar al catálogo. |
| **Navigation** | Es lo primero que se ve al entrar. Abrir un producto lleva a su ficha. | Se llega solo al abrir un producto desde el catálogo. "Volver" regresa al catálogo. |
| **Empty / error state** | "Todavía no hay productos en esta categoría. Prueba con otra." | "No encontramos este producto. Vuelve al catálogo para seguir explorando." |
